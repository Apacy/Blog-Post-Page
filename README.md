# Blog Post Page

This is a Blog Post Page project for [roadmap.sh](https://roadmap.sh/projects/blog-post-page).

## Technologies Used

* HTML5

## Key Features

* Semantic HTML structure using proper heading hierarchy (`h1`–`h5`)
* `<article>` for the main blog content with a `<time>` element for the publish date
* `<figure>` and `<figcaption>` for the illustrative image
* `<blockquote>` with `<cite>` for a quoted source
* `<code>` and `<pre>` for inline and block code samples
* Header with site navigation and footer with copyright

## How to Run

1. Download the `blog-post-page` folder
2. Ensure it contains:
   * `index.html`
   * `mountains-at-sunrise.png`
3. Open `index.html` in your preferred web browser

## Project Structure

```
blog-post-page/
│
├── index.html               # Main HTML file
└── mountains-at-sunrise.png # Blog post image
```

## Semantic HTML Highlights

* `<header>` with `<nav>` for site-wide navigation
* `<main>` wrapping the primary page content
* `<article>` for the self-contained blog post
* `<time datetime="...">` for machine-readable publish dates
* `<figure>` + `<figcaption>` pairing an image with its caption
* `<blockquote>` + `<cite>` for properly attributed quotes
* Proper document metadata: `<title>`, `<meta charset="UTF-8">`, `<meta viewport>`

## Customization

Edit the content inside `<main>` in `index.html` to write your own blog post. Replace `mountains-at-sunrise.png` with your own image and update the `alt` and `<figcaption>` text accordingly.
